# Security

Kaydence keeps people's private diaries, so security problems are taken seriously. Thank you for helping keep it safe.

## Reporting a security problem

Please **don't** open a normal public issue for a security problem, because that would tell everyone about it before it's fixed.

Instead, report it privately through GitHub:

1. Go to the [Security tab](https://github.com/KaydeeCodes/Kaydence/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, which version of Kaydence you used, and the steps to make it happen.

Only the maintainer can see private reports. You'll get a reply as soon as possible, usually within a week, and you'll be kept up to date while it's being fixed. If you'd like to be thanked by name in the release notes, just say so.

## What counts as a security problem

For example:

- A way to read an encrypted diary without the password or recovery file
- A way to get past the lock screen
- Anything from a diary ending up somewhere it shouldn't, such as a log, a bug report or the internet
- A way for a file, picture or link to make Kaydence do something harmful

## Supported versions

Only the latest release gets security fixes. Kaydence checks for updates once a day and offers the new version.
