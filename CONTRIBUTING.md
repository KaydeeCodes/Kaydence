# Contributing

Thank you for wanting to help make Kaydence better.

## Ideas and problems are very welcome

- **Found a problem?** Please [open a bug report](https://github.com/KaydeeCodes/Kaydence/issues/new?template=bug_report.yml). In Kaydence, Settings, Help and feedback, **Make a bug report** creates a zip of the logs to attach. It never contains anything from your diary.
- **Got an idea?** Please [suggest a feature](https://github.com/KaydeeCodes/Kaydence/issues/new?template=feature_request.yml). Saying why it would help you is the most useful part.
- **Found a security problem?** Please report it privately, see [SECURITY.md](SECURITY.md).

## Code contributions

Kaydence is developed by one person, and pull requests aren't being accepted at the moment. The code is public so anyone can see exactly what Kaydence does with their diary.

The [licence](LICENSE) doesn't allow sharing changed versions of Kaydence, so please don't publish forks with changes. If there's something you'd love to see, an issue is the best way to make it happen.
